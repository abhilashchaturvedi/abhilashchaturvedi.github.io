# Portfolio

Static portfolio site with no dependencies. Content lives in `content/`, `build.mjs` generates `dist/`.

```
node build.mjs     # build
npx serve dist     # preview (or open dist/index.html)
```

- Add a project: new entry in `content/projects.json`, rebuild.
- Add a skill track or planned item: edit `content/site.json`.
- Only publish work you did yourself. No employer-confidential material.
